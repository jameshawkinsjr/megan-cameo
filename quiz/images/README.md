Images for the quiz go here.

**Show logos** (intro screen, so the names stay secret until the reveal):

- `summer-house-logo.png`: Summer House
- `rhony-logo.png`: The Real Housewives of New York City

Use transparent PNGs (or SVGs; update the path in `quiz/config.js`) in a light color so they
read on the dark background. Until a file is added, a typographic wordmark of the show name is shown.

**Portraits** (result and Cameo screens):

- `kyle.jpg`: Kyle Cooke
- `bethenny.jpg`: Bethenny Frankel

Portrait orientation (about 4:5, ~800×1000px or larger) looks best. Until a file is added,
a monogram card is shown.

To change file names or the portrait crop (`position`), edit `PEOPLE` in `quiz/config.js`.
